# Analyse des alertes système

## 1. Présentation

Ce projet est un exercice Python réalisé dans le cadre de la formation sur l'intelligence artificielle et les infrastructures IA en entreprise.

L'objectif est d'analyser un fichier CSV contenant des alertes système et de compter le nombre d'alertes par niveau de gravité.

## 2. Technologies utilisées

- Python 3
- Module `csv`
- Dictionnaires Python
- Boucles `for`

## 3. Structure du projet

```text
massamba@Massamba:~/ia-entreprise-lab/seance-00-python-bases/test2/
├── alertes.csv
├── analyse_altertes.py
└── README.md
```

## 4. Exécution du programme

Depuis le terminal, exécuter :

```bash
python analyse_altertes.py
```

## 5. Résultat obtenu

```text
INFO : 2
WARNING : 2
CRITICAL : 2
ERROR : 1
```

Le programme a analysé 7 alertes au total.

- Lire un fichier CSV avec Python.
- Parcourir des données avec une boucle.
- Utiliser un dictionnaire pour compter des occurrences.
- Afficher un résultat dans le terminal.
- Documenter un petit projet informatique.
